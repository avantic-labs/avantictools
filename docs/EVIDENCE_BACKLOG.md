# AVANTIC Tools evidence backlog

Use this file for observed evidence and proposed product changes. Hypotheses are
not findings. Do not record user content, filenames, raw search phrases or other
sensitive details here.

## Entry template

### Observation
What actually happened?

### Evidence
Which metric, safe event aggregate or user report supports it? Include the date
range and sample size.

### Hypothesis
Why might it be happening?

### Confidence
Low / medium / high.

### Proposed change
What is the smallest intervention?

### Success metric
How would we know it worked?

### Status
Observing / proposed / approved / testing / validated / rejected.
