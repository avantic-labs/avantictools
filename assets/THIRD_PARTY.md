# Third-party assets

The approved product artwork was supplied by the Founder and remains unchanged
apart from proportional identity crops/resizing.

- Inter: [Inter project](https://github.com/rsms/inter), SIL Open Font License
  (`fonts/OFL.txt`). The full static font is used for local invoice exports;
  npm `@fontsource/inter` provides the self-hosted UI subsets.
- PDF.js: Mozilla, Apache 2.0 (`licenses/pdfjs.txt`). Runtime worker, CMaps,
  standard fonts and WebAssembly assets are copied from the installed package;
  their bundled notices remain intact.
- pdf-lib: MIT (`licenses/pdf-lib.txt`).
- @pdf-lib/fontkit: MIT, as declared in its [source README](https://github.com/Hopding/fontkit#license).
- Lucide: ISC, with included Feather attribution (`licenses/lucide.txt`).

All runtime processing assets are served from this application’s origin.
